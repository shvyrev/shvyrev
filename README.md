### About

I'm a hands-on platform architect with 17 years across distributed systems, real-time
infrastructure (telecom, fintech) and AI platforms. I'm most effective where the problem is
not fully defined yet: shaping architecture from business and technical constraints, validating
difficult decisions through PoCs, and staying in code through production.

- 🏗️ **Founder of [Atrium](https://atrium-ai.ru)** — a commercial on-premise LLM platform built
  from zero: OpenAI-compatible model serving, multi-tenant team workspaces, per-model access
  control and quotas, AD/LDAP integration, full audit journal. In pilot; rollout across 5 data
  centers targeted for February 2027.
- 🧭 **Before that:** technical lead of a commercial SaaS MLOps/LLMOps platform (enterprise
  control planes over mTLS, LLM endpoints provisioned in ~15 minutes); 5.5 years modernizing
  business-critical 24×7 voice services at Bezeq International — SIP routing tier scaled
  **~8–10×** under extreme production traffic surges.
- ☕ **Stack:** Java 21 / Quarkus · event-driven control planes (transactional outbox →
  Debezium → Kafka → Knative) · KServe / Kubeflow · Kubernetes · Keycloak · PostgreSQL.
